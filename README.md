🎮🤖 StratBot

An AI-Powered Game Strategy Chatbot built using Google Gemini API and Flask

📌 Project Overview

StratBot is an intelligent chatbot designed to provide real-time game strategies, tips, and performance improvement guidance for players.

It leverages Google Gemini 1.5 Pro to generate smart, context-aware responses focused on gaming and sports strategy.

The chatbot filters non-gaming queries and maintains a focused, strategy-oriented interaction experience.

🚀 Features

🎯 Real-Time Game Strategies
Get expert tips, tricks, and winning strategies for various games.

🧠 Gemini 1.5 Pro Integration
Powered by Google Gemini for intelligent and high-quality responses.

⚽ Sports Strategy Insights
Ask about athletes (e.g., Ronaldo) and receive performance improvement advice.

💬 Friendly Chatbot Interaction
Handles greetings and casual conversation smoothly.

🔍 General Knowledge Filtering
Redirects non-gaming questions politely to maintain topic relevance.

🏗️ Tech Stack

Backend

⚙️ How to Run the Project

Clone the repository:

git clone <your-repo-link>
cd stratbot


Create a .env file in the root directory and add your Gemini API key:

GEMINI_API_KEY=your_api_key_here


Install dependencies:

pip install -r requirements.txt


Run the Flask application:

python app.py

The objective of StratBot is to create an AI-powered assistant focused on:

Enhancing gaming performance

StratBot demonstrates the integration of AI APIs with web applications using Flask.
